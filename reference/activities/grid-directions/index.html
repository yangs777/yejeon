교사용 준비·진행 안내

활동 목표

칸 이름과 기준 방향을 합의하고, 설명을 듣고 배치한 결과와 원본을 비교합니다.

준비물

같은 격자 인쇄물 2장, 작은 종이 모양 3개, 연필. 위쪽에 표시된 방향을 서로 먼저 확인합니다.

진행 순서

  1. 기준 5분 - 왼쪽부터 A~D, 위쪽부터 1~4임을 확인합니다. 지도를 같은 방향으로 둡니다.
  2. 배치 10분 - 종이 모양 3개를 서로 다른 칸에 놓고 이름과 칸을 기록합니다.
  3. 전달 10분 - 원본을 보여 주지 않고 칸 이름이나 이동 방향을 설명합니다.
  4. 비교 15분 - 원본과 재현한 칸을 비교한 뒤 방향과 출발점 설명을 보완합니다.

함께 나눌 질문

  • 오른쪽 한 칸의 기준이 두 사람에게 같았나요?
  • 칸 이름으로 말할 때와 이동 방향으로 말할 때 무엇이 달랐나요?

기록 예시

설명 예: A1에서 시작해 오른쪽 두 칸, 아래 한 칸으로 이동하면 C2입니다. 격자는 위쪽부터 행 번호가 커집니다.

결과를 해석할 때

이 격자는 위치 설명을 위한 지도입니다. 실제 거리나 축척을 나타내는 실측 지도라고 표시하지 않습니다.

쉬운 시작과 확장

처음에는 칸 이름만 사용합니다. 확장할 때는 출발점에서 여러 번 이동하는 설명으로 바꾸고, 중간 위치도 기록합니다.

사용 전에 자주 묻는 점

보는 방향이 다르면요?

위쪽 표시를 맞춘 뒤 다시 설명합니다. 방향 기준을 합의하는 것도 활동의 일부입니다.

바둑판처럼 격자선 위에 놓나요?

이 활동은 선의 교차점이 아니라 칸 안에 놓습니다. 시작 전에 이 규칙을 함께 확인합니다.
